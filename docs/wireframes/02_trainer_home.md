## 설계 의도

### 1. 정보 우선순위 (위→아래)
북극성 원칙(`develop_plan` §0.1 의사결정 기반) 순서:
1. **오늘 수업** — 즉시 동선 (회원 기다리는 상황 대응)
2. **AI 검수 대기** — 한가할 때 처리할 작업 (강요 X)
3. **재등록 임박** — 매출 직결, 잊지 않도록 항상 노출

### 2. 검수 카드를 "검수 안 함"으로 둘 수 있는 자유
- AI 검수는 강제가 아님. 검수 대기 N건은 단순 정보 표시
- 트레이너가 무시하면 메시지는 자동 발송 안 됨 (`outgoing_notifications.status='draft'` 유지)
- 메모는 트레이너 본인만 보는 영역이라 검수 안 해도 회원에게 영향 없음

### 3. 재등록 임박 카드의 "[안내 메시지 보내기]" 동작
- 탭 → AI-B 초안 즉시 생성 → AI 검수 화면(`06_ai_review.md`)으로 이동
- 즉, 트레이너가 의도적으로 안내 메시지를 트리거하는 경로도 제공
- (자동 cron 외에 수동 트리거 옵션)

### 4. 하단 탭바 가운데 `📝+`
- 1분 입력 KPI 달성을 위한 최단 동선
- 수업 끝나자마자 화면 가운데 큰 버튼 탭 → 회원 선택 → 기록 입력
- 가운데 탭은 약간 더 크게 시각적 강조 (FAB 스타일로 변형 가능 — 친구 리뷰 항목)

### 5. 🔔 알림 아이콘
- 푸시 도착 이력 (재등록 알림 발송 완료, AI 초안 새로 생성됨 등)
- 5건 = 미확인 알림 개수

### 6. 회원 신호등 색상
- 🟢 정상 (잔여 6회 이상 + 활발)
- 🟡 주의 (잔여 5회 이하 또는 만료 14일 이내)
- 🔴 위급 (잔여 1~2회 또는 만료 7일 이내)
- ⚪ 비활성 (마지막 수업 14일 이상 경과)

> 색상 임계값은 v0.2에서 친구 의견 반영해 조정.
