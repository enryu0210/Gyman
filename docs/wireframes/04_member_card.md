## 설계 의도

### 1. 🔒 트레이너 전용 메모 영역의 시각적 분리
- **다른 배경색 + 자물쇠 아이콘 + "회원에게 보이지 않음" 명시**
- 트레이너가 화면 캡처를 회원에게 보여주는 실수도 줄임
- 데이터 모델 §3 RLS의 `notes_owner_rw` + `notes_member_deny`로 백엔드는 이미 차단

### 2. 메모 카드 내 출처 표기 (`ⓘ`)
- `ⓘ 직접 입력` — 트레이너가 손으로 작성 (`source='manual'`)
- `ⓘ AI 확정` — AI가 만들고 트레이너가 확정 (`source='ai_confirmed'`)
- `ⓘ AI 초안` — 미확정 (`source='ai_draft'`, 별도 검수 화면에서만 노출)
- audit 일관성을 위해 표기 유지 (develop_plan §6)

### 3. AI 초안 N건은 메모 영역 상단에 알림 카드로
- 클릭 → AI 메모 검수 화면(`06_ai_review.md`)으로 이동, 회원 필터 적용

### 4. "목적/배경"과 "트레이너 전용 메모"의 차이
- **목적/배경**: 회원도 본인 카드에서 확인 가능 (Phase 2 회원 앱)
  - 회원이 "내 트레이너가 내 목표를 이해하고 있다"고 느끼는 데이터
- **트레이너 전용 메모**: 영업/심리 관련, 회원에게 보이면 곤란한 데이터
- 이 분리는 **DB 레이어부터 강제**되어 있음 (`member_profiles` vs `member_notes`)

### 5. "재등록 안내 보내기" 동작
- 탭 → AI-B로 회원 특성 반영한 안내 메시지 즉시 초안 생성
- AI 메시지 검수 화면(`06_ai_review.md`)으로 이동, 발송 채널 선택
- (자동 cron 알림 외 수동 트리거 경로)

**AI 동의 처리**
- 기본값은 "동의 안함" (안전한 기본값)

- 동의 컬럼은 `member_profiles.ai_consent boolean DEFAULT false` (data_model §8 미정 항목)
- 거부 회원은 자동 발송 대상에서 제외, 메모 초안도 생성 X
