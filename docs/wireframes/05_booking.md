# 05. 예약 캘린더 + 노쇼/취소 처리

> 라우트: `/trainer/booking`, `/trainer/booking/:id`
> 대응 작업: Phase 1 / 1.6
> 핵심: **노쇼/당일취소 시 차감 규정 자동 표시 + 기록으로 남김 → 분쟁 시 근거**

- 색상: 회색(완료) / 파랑(예정) / 주황(이상 발생)

## 설계 의도

### 1. 라디오 버튼으로 상태 단순화
- `session_status` ENUM(`scheduled/done/no_show/canceled/late_cancel`)을 그대로 노출
- 차감 여부를 각 옵션 옆에 명시 → 트레이너가 의사결정 시 바로 확인

### 2. 차감 규정 항상 표시
- "이 센터의 PT 규정" 박스를 화면에 고정 노출
- 데이터 출처: `centers.rules` JSONB 필드
- 트레이너가 회원에게 화면 보여주며 설명 가능 → **분쟁 사전 차단**

### 3. 메모 자유 입력
- 회원이 보낸 카톡 내용, 통화 메모 등을 남길 수 있음
- 분쟁 시 트레이너의 일관된 기록 입증

### 4. 상태 변경 이력
- 운영 단계 고려: "예정→당일취소" 변경 시각, 변경자 로깅 필요
- DB 레이어에 `session_status_history` 테이블 또는 `audit_log` 통합 검토 (data_model §8 후속 항목 추가 권장)

### 5. "✅ 완료" 선택 시 수업 기록 화면으로 이동
- 완료 = 운동 기록이 있어야 함
- 라디오 탭 → 수업 기록 화면으로 자동 진입 → 저장 후 자동 status='done' 처리
- 트레이너 동선: 예약 셀 탭 → "완료" → 기록 입력 → 저장 → 모두 끝

## 화면 5.4 — 노쇼/당일취소 직후 토스트

```
┌────────────────────────────────────────────────────┐
│  ┌──────────────────────────────────────────┐    │
│  │ ✓ 박지훈 19:00 수업: 당일 취소 처리됨    │    │
│  │   잔여 6회 → 5회 (-1회)                  │    │
│  │                                          │    │
│  │   회원에게 차감 안내 보낼까요?           │    │
│  │                                          │    │
│  │            [지금 안내]  [나중에]         │    │
│  └──────────────────────────────────────────┘    │
└────────────────────────────────────────────────────┘
```

- "지금 안내" → AI-B로 차감 안내 메시지 초안 생성 → 검수 화면 진입
- "나중에" → 토스트 닫힘, 트레이너가 원할 때 회원 카드에서 수동 발송 가능
- 자동 발송은 X — 회원 감정 케어 차원 (트레이너 판단 영역)
