## 1분 입력을 위한 UX 핵심 결정

### 1. 회원 자동 선택
- 진입 시점이 수업 시간 ±30분 이내면 해당 회원 자동 선택
- 진입 시점이 애매하면 "오늘 예정 회원 리스트" 드롭다운 상단 노출
- 회원 카드에서 진입한 경우(`/trainer/members/:id` → 기록 버튼)는 해당 회원 고정

### 2. "복사 ⎘" 버튼 = 이전 회차 복사
- 같은 회원의 직전 수업에서 같은 종목의 무게·반복을 그대로 채워줌
- 트레이너는 변경분만 손대면 됨
- **이게 1분 입력의 핵심**

### 3. 자주 쓰는 종목 빠른 추가
- 트레이너별 사용 빈도 Top 5 표시
- 한 번 탭으로 종목 추가 + 직전 회차 무게/세트 자동 채움

### 4. 컨디션은 라디오 3단계만
- 텍스트 자유입력 X (입력 마찰)
- 보통(😐) 기본 선택 → 다를 때만 변경
- 데이터 분석 시 일관성도 확보

### 5. "통증/특이" "다음 메모"는 옵션
- 비워도 저장 가능
- 입력 안 하면 AI 메모 초안 생성도 안 함 (또는 빈 초안)
- 트레이너가 부담 없이 빈 메모로 빠르게 저장 가능

### 6. 저장 후 자동 화면 전환 X
- 저장 → 토스트("수업 기록 저장됨. AI 메모 초안 생성 중...") → 홈 복귀
- AI 검수 화면으로 자동 이동 시 입력 흐름 끊김
- 트레이너가 한가할 때 홈의 검수 카드를 통해 일괄 처리

## 화면 3.3 — 세트 입력 (인라인)

종목 카드 내 세트 입력은 인라인 편집. 모달 X.

```
┌──────────────────────────────────────────┐
│ 스쿼트                          [복사 ⎘] │
│  ┌─────┬─────┬─────┬─────┐               │
│  │60×10│70×8 │70×8 │  +  │               │
│  └─────┴─────┴─────┴─────┘               │
│                                          │
│  세트 4 추가 →                           │
│  무게 [___]kg  반복 [__]회  [추가]      │
└──────────────────────────────────────────┘
```

- 기존 세트 탭 → 인라인 수정
- "+" 탭 → 무게/반복 입력 필드 펼침
- 직전 세트값 자동 prefill

- LLM 호출 실패 시 토스트 내용 변경: "✓ 저장됨. AI 메모 생성 실패 (수동 입력 가능)"

## 화면 3.5 — 수업 기록 상세/수정 (`/trainer/session/:id`)

이미 저장된 기록을 다시 열 때. 화면 3.1과 거의 동일하되:
- 상단에 "마지막 수정: 2026-05-24 14:32" 표시
- 저장 버튼 → "수정 저장"으로 라벨 변경
- 수정 시 AI 메모 초안 **재생성 X** (이미 생성된 초안이 있으면 새로 만들지 않음, 비용/혼란 방지)
- 단, 수동 "AI 메모 재생성" 버튼은 제공
